Ex. 1 — Riemann and Lebesgue integration

Riemann: partition the domain

Cut [a, b] into subintervals [xi−1, xi], pick a tag ξi in each and add up the areas of the rectangles:

$$\int_a^b f \;=\; \lim_{\|P\|\to 0}\; \sum_{i=1}^{N} f(\xi_i)\,(x_i - x_{i-1}).$$

The limit must exist and be the same for every choice of tags (equivalently, upper and lower Darboux sums must meet).

Lebesgue: partition the range

Cut the values into levels y0 < y1 < … and measure the set of points where f falls in each level (its preimage):

$$\int f\,d\mu \;=\; \lim_{\Delta y\to0}\;\sum_{k} y_k\;\mu\bigl(f^{-1}[y_k, y_{k+1})\bigr) \;=\; \int_0^{\infty} \mu\{x : f(x) > t\}\,dt .$$

The last expression (for f ≥ 0, the “layer-cake” formula) integrates the distribution function of f over the values.

Lebesgue's own analogy: Riemann counts coins in the order they come out of the pocket; Lebesgue first sorts them by value and counts how many of each kind there are.

Pathological functions

Dirichlet's function: 1 on the rationals, 0 on the irrationals

Every subinterval, however small, contains both rationals and irrationals. A Riemann sum with rational tags is always 1, with irrational tags always 0: the upper Darboux sum is 1 and the lower is 0 for every partition, so the Riemann integral does not exist. For Lebesgue the question is just the measure of the preimage of the value 1, that is of ℚ ∩ [0, 1]. A countable set has measure zero: list the rationals q1, q2, … and cover qi with an interval of length ε/2i; the total length is at most ε, for any ε > 0. Hence

$$\int_0^1 \mathbf 1_{\mathbb Q}\,d\mu = 1\cdot\mu(\mathbb Q\cap[0,1]) + 0\cdot\mu([0,1]\setminus\mathbb Q) = 1\cdot 0 + 0\cdot 1 = 0 .$$

A numerical warning: every floating-point number is a rational (a fraction with a power of 2 in the denominator). A program that tests “x is rational” on doubles would answer yes for every sample, and any sampling method would return 1. The value 0 comes from measure theory, not from evaluating f: no finite computation can see the difference between ℚ and the irrationals.

Thomae's function: 1/q at x = p/q, 0 at irrationals

Thomae's function is discontinuous at every rational and continuous at every irrational. Its set of discontinuities has measure zero, so by Lebesgue's criterion it is Riemann integrable, and both integrals are 0 (Lebesgue: f > 0 only on the countable set ℚ). The Riemann sums do converge, but slowly: in every subinterval there is a fraction with a small denominator.

Discussion

  • Same value for Riemann-integrable functions. Whenever the Riemann integral exists, the Lebesgue integral exists and is equal (it is a theorem). The tables confirm it numerically: every method converges to the same reference value for all the regular examples.
  • Accuracy. For smooth functions the Riemann-type rules are much more accurate per unit of work: midpoint and trapezoid errors decrease as N⁻², Simpson as N⁻⁴. Lebesgue lower/upper sums decrease only as M⁻¹, and the mid-level rule as M⁻² only if the distribution function t ↦ μ{f > t} is smooth.
  • A duality of difficulties. Riemann struggles where f changes fast (jumps, steep parts, singularities); Lebesgue struggles where f is flat: near a maximum or minimum the preimage of a thin level is a wide interval, μ{f > t} has a square-root singularity, and the mid-level rule drops to about M⁻¹·⁵ (sin x near π/2, x² near 0). For |x − ½|, whose distribution function is linear, the Lebesgue sum is exact.
  • Discontinuities and simple functions. For step functions Lebesgue is natural: if the levels contain the values taken by f, the sum is exact with a handful of levels. Riemann rules are exact only when the jumps fall on grid points, otherwise they lose one subinterval's worth of accuracy (error ∝ 1/N).
  • Unbounded functions. 1/√x has no proper Riemann integral: rules that evaluate f(0) return ∞ and the midpoint rule converges only as N⁻¹ᐟ². Partitioning the range handles the singularity naturally, since μ{1/√x > t} = 1/t² is explicit; truncating the levels at T = M²ᐟ³ gives an error of order M⁻²ᐟ³.
  • Computational efficiency. A Riemann sum needs only evaluations of f. A Lebesgue sum needs the measures of preimages: cheap when the inverse is known, but in general it requires root finding (sin x / x: about 60 evaluations of f per level) or sampling the domain (counted preimages, sin(1/x)), which is a Riemann sum in disguise plus a sorting step. This is why numerical quadrature is Riemann-style in practice.
  • Where they really differ. Dirichlet's function: no Riemann integral, Lebesgue integral 0. The indicator of a “fat” Cantor set (positive measure, empty interior) behaves the same way. The power of Lebesgue's definition is theoretical: it integrates many more functions and allows limits to be exchanged with integrals (monotone and dominated convergence), which is what probability theory is built on.

Ex. 2 — Numerical computation of the normal CDF

$$\Phi(x) = P(Z \le x) = \int_{-\infty}^{x} \varphi(t)\,dt, \qquad \varphi(t) = \frac{1}{\sqrt{2\pi}}\,e^{-t^2/2}.$$

Why there is no formula with elementary functions

Elementary functions are those built from rational functions, exp, log and roots with finitely many arithmetic operations and compositions. Whether an elementary function has an elementary antiderivative is decided by Liouville's theorem (1835, made algorithmic by Rosenlicht and Risch). Its special case for functions of the form g·eh reads:

$$\begin{gathered}\text{If } g,\ h \text{ are rational functions, } g \neq 0 \text{ and } h \text{ is not constant, then}\\[4pt] \int g(x)\,e^{h(x)}\,dx \ \text{ is elementary} \iff \exists\, R \text{ rational with } g = R' + h'R .\end{gathered}$$

In that case the antiderivative is R(x)eh(x). For φ we have g = 1 and h = −x²/2, so we would need a rational R with

$$R'(x) - x\,R(x) = 1 .$$
  • If R were a polynomial of degree d ≥ 0, then x·R has degree d + 1 while R′ has degree d − 1: the left side has degree d + 1 ≥ 1 and cannot equal the constant 1 (and R = 0 gives 0 ≠ 1).
  • If R had a pole of order k ≥ 1 at some point c, then R′ would have a pole of order k + 1 at c, which neither x·R (order at most k) nor the constant 1 can cancel.

So no such R exists, and $\int e^{-x^2/2}dx$ (hence Φ) is not an elementary function. This is the result quoted in the course notes (Hogg–McKean–Craig, §3.4) when they say that φ has no closed-form antiderivative and Φ must be tabulated.

The error function: an exact representation

The error function is defined as the missing antiderivative, suitably normalized:

$$\operatorname{erf}(z) = \frac{2}{\sqrt\pi}\int_0^z e^{-u^2}\,du .$$

Using the symmetry Φ(0) = ½ and the substitution t = √2·u:

$$\Phi(x) = \frac12 + \int_0^x \varphi(t)\,dt = \frac12 + \frac{1}{\sqrt{\pi}}\int_0^{x/\sqrt2} e^{-u^2}du = \frac12\Bigl[1 + \operatorname{erf}\Bigl(\frac{x}{\sqrt2}\Bigr)\Bigr] = \frac12\operatorname{erfc}\Bigl(-\frac{x}{\sqrt2}\Bigr).$$

This is an exact analytical representation: erf is a special function, a non-elementary function that is given a name because it appears everywhere, with a whole theory of its properties (series, continued fractions, asymptotic expansions, derivatives, symmetries). But naming the integral does not evaluate it: to get the digits of erf(1.3) someone still has to run an algorithm, just as for sin or exp. Libraries such as C's erf/erfc use carefully tuned rational approximations; JavaScript has no Math.erf at all, so here every method is implemented from scratch.

Accuracy and efficiency

Conclusions

  • Numerical integration is the most direct route (Φ is an integral) but the least efficient: about 100 evaluations of the exponential for 10⁻¹⁰ (Simpson), and it cannot deliver small tail probabilities with relative accuracy, because the result is formed as ½ + (an integral close to −½).
  • The alternating Taylor series of erf converges for every x in exact arithmetic but is useless in floating point for |x| ≳ 5: its terms grow to about ex²/2 before shrinking, and the cancellation destroys all digits (errors of order 10³ at x = −10).
  • The positive series has no cancellation and is accurate in the centre; the continued fraction is excellent in the tails but fails at x = 0. Each method has a region where it is good: this is typical of special functions.
  • Combining them (series for |x| < 2.5, continued fraction otherwise, always computing the smaller tail first and then using Φ(−x) = 1 − Φ(x)) gives errors at the level of rounding: absolute error ≈ 2·10⁻¹⁶ and relative error ≈ 10⁻¹⁴ even at Φ(−10) ≈ 7.6·10⁻²⁴, in a few hundred nanoseconds.
  • Closed-form rational approximations (A&S) are the fastest (a single exponential and a few multiplications) with 7 correct digits: perfect for tables and most statistics, not for extreme tails. Production libraries use the same idea with more coefficients and several intervals (e.g. Cody's algorithm) to reach full double precision.
  • The role of erf. Liouville's theorem tells us that no finite formula in elementary functions exists; erf gives the CDF an exact name and a theory, but its values still come from numerical algorithms, exactly like those of sin, exp or log, which are also computed by series and rational approximations behind the scenes.
